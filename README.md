A single funny line for the make.fun bounty "The One-Line Laugh": one sentence, at most 200 characters, with the surprise saved for the very end. The program writes the line to `/output/entry.txt` — deterministic, no randomness, no network, no file reads at runtime.

## Run it

```sh
node main.ts
```

This writes the line to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when set) and logs the character count.
